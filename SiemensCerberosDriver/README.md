# SiemensCerberosDriver

Материалы по драйверу интеграции АПС Siemens Cerberus PRO в R-Платформу (разработчик — ООО «Рубеж»).

## Цель

Интеграция системы АПС на базе Siemens Cerberus PRO в R-Платформу: приём сигналов и событий, управление системой АПС, архивирование, доступ сторонних систем через API. Планируется продолжение контракта на интеграцию.
