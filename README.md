# R-Platform

Репозиторий проекта по интеграции и внедрению **ПАК ИСБ на базе R-PLATFORMA** — программно-аппаратного комплекса интегрированной системы безопасности для объекта «Генеральный план», с. Оползневое, г. Ялта.

## О проекте

Проект охватывает объединение разнородных систем безопасности объекта в единую платформу управления:

- **СКУД** — системы контроля и управления доступом (Sigur, Salto)
- **СОТ** — системы охранного телевидения (Интеллект, Dahua, Mobotix, Hikvision)
- **СОТС** — системы охранно-тревожной сигнализации (Satel Integra, «Волк»)
- **АСКДРМ** — автоматизированная система контроля доступа к рабочим местам
- **TETRA** — транкинговая радиосвязь
- Интеграция с ГИС-картами объекта и OPC/SCADA-модулями

## Структура репозитория

```
/original_docs  — Официальная документация. Договоры, приложения, технические задания, письма. Все документы в исходных форматах, официально заключенная между контрагентами. 
/planning - текущие документы с которыми производится работа.


```

> Структура будет уточняться по мере наполнения репозитория рабочими материалами.

## Ключевые технические ограничения

- Требования к серверной части: Astra Linux / Windows, поддержка виртуализации и контейнеризации
- Резервирование серверной инфраструктуры: схема 2N
- Целевое время реакции системы: 2.5–3 сек
- Лицензирование модулей поэтапно (см. `/specs`)
