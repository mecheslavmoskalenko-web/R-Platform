# training — Материалы обучения

Материалов не получено.

По ТЗ в состав 1-го этапа входит обучение:

- операторов — до 20 человек
- администраторов — 6 человек

Доступ к конфигурированию и администрированию ПАК ИСБ предоставляется только
специалистам с персональными аттестатами по администрированию R-PLATFORMA
либо включённым в список сертифицированной организации-партнёра — то есть
обучение завязано на аттестацию у вендора.

К запросу у разработчика: программа курса, учебные материалы, порядок
и сроки аттестации, форма выдаваемого аттестата.
