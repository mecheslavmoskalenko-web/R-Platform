# operator — Руководство пользователя R-PLATFORMA

Документ для АРМ оператора ЦПБ. Парная редакция к руководству администратора
от 21.07.2025.

| Файл (целевое имя) | Дата | Стр. | Размер |
|---|---|---|---|
| `Руководство_пользователя_2025-07-21.pdf` | 21.07.2025 | 995 | 286 МБ |

## Состав

- Назначение и условия работы R-PLATFORMA
- Запуск, главный интерфейс, панели пользователя и их назначение
- Время
- **Журнал инцидентов** — просмотр информации по инциденту, поиск, создание фильтров,
  просмотр камер и видеоархива
- **Журнал событий**
- Создание инцидента вручную
- **Выполнение рабочей процедуры по обработке и закрытию инцидента** — механизм СОП
- Календарь событий
- **Интерактивная карта** — отображение планов объектов, режимы 2D и 3D, слои,
  информационные панели, получение информации по локации, навигация, пресеты
  для быстрого перехода, панорамирование

## Связь с проектом

Разделы «Журнал инцидентов», «Рабочая процедура» и «Интерактивная карта» —
прямое соответствие требованиям ТЗ по СОП, ситуационному управлению и визуализации
на интерактивной карте в формате 2D. Раздел по карте — основной источник
по подсистеме ГИС.
