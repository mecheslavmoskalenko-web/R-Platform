# gis — Подсистема ГИС-карт

Отдельной документации по серверу ГИС-карт не получено.

Источники по теме в имеющихся материалах:

- **Руководство пользователя (21.07.2025)**, раздел «Интерактивная карта» — отображение
  планов объектов, режимы 2D/3D, слои, информационные панели, навигация, пресеты.
- **Руководство администратора** — настройка местоположения оборудования
  (вкладка «Местоположение» в разделе интеграции).

## Что требуется запросить у вендора

- описание сервера ГИС-карт как отдельного компонента (лицензия на подключение
  сервера ГИС-карт входит в этап 1)
- форматы импорта планов (по ТЗ исходные планы предоставляются в PDF или DWG,
  подлежат преобразованию в формат R-PLATFORMA — 120 планов)
- API/протоколы обмена геоданными — для интеграции с ЕЦ МиР
- схема хранения геометрии и привязки оборудования к планам
