## Различия редакций (по оглавлению)

**10.02.2025**
- Видеоподсистема названа «Видеосистема R-Operator»
- Есть отдельный подраздел «Особенности работы с таблицами интеграции»
- Импорт пропусков: Perco, Prowatch (раздел помечен как в разработке)
- Нет вкладок «Конфигурация Систем» и «Импортированные шаблоны доступа»

**21.07.2025**
- Видеоподсистема переименована в «Видеосистема»
- Импорт пропусков развёрнут в подразделы: интегрированные системы, расписания
  доступа, шаблоны доступа, пользователи
- Добавлены вкладки «Конфигурация Систем» и «Импортированные шаблоны доступа»

**19.12.2025**
- Добавлен раздел «Содержание руководства администратора»
- Расширен перечень методик интеграции ИС

## Ключевые разделы

- Назначение и условия работы R-PLATFORMA
- Запуск, активные сессии пользователей, журнал аудита
- Видеоподсистема
- Звуковые оповещения по событиям и инцидентам
- Импорт пропусков (в т.ч. из PERCo)
- Интеграция систем: вкладки «Общее», «Местоположение», «Типы ИС», «ИС»,
  «Конфигурация Систем», «Импортированные шаблоны доступа»
- Конфигурация ИС
- Методики интеграции ИС с R-PLATFORMA (см. `../integration/README.md`)
