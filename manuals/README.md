# manuals

Эксплуатационная и техническая документация на ПАК R-PLATFORMA (ГК «Рубеж»).

## Назначение

Раздел для хранения документации, получаемой от разработчика платформы и партнёрского канала:

- руководство администратора R-PLATFORMA
- руководство оператора / АРМ
- описание интеграционных интерфейсов (API, OPC, webhooks)
- описание модулей и лицензируемого функционала
- описание подсистемы ГИС-карт
- материалы обучения операторов и администраторов

## Структура

```
/manuals
  /admin          — администрирование и конфигурирование
  /operator       — руководства оператора и АРМ
  /integration    — API, протоколы, форматы обмена
  /gis            — подсистема ГИС-карт
  /training       — материалы обучения (20 операторов, 6 администраторов)
```

## Статус

Раздел создан. Документация от вендора не получена — подлежит запросу в рамках 1-го этапа
до проведения обучения персонала.

## Примечание

Доступ к администрированию ПАК ИСБ по условиям ТЗ возможен только для специалистов
с персональными аттестатами по администрированию R-PLATFORMA либо включённых в список
сертифицированной организации-партнёра. Материалы раздела распространяются с учётом NDA.
