## Ограничение по размеру файлов

GitHub жёстко отклоняет файлы свыше 100 МБ. Четыре основных руководства весят
269–316 МБ каждое (суммарно ~1,1 ГБ) и в обычный git-репозиторий не помещаются.

Варианты размещения:

1. **Git LFS** — включить для репозитория, добавить `.gitattributes`
   с правилом `*.pdf filter=lfs diff=lfs merge=lfs -text`. Лимит на файл — 2 ГБ,
   но нужна оплаченная квота хранилища/трафика.
2. **Внешнее хранилище** (Яндекс Диск, файловый сервер проекта) — в репозитории
   остаются только каталожные файлы и ссылки. Наиболее вероятный рабочий вариант
   с учётом NDA.
3. **Оптимизация PDF** — руководства состоят преимущественно из растровых
   скриншотов без сжатия; пережатие изображений даёт сокращение в разы,
   но искажает читаемость интерфейсных снимков.

## Примечание по режиму доступа

По условиям ТЗ доступ к администрированию ПАК ИСБ возможен только для специалистов
с персональными аттестатами по администрированию R-PLATFORMA либо включённых
в список сертифицированной организации-партнёра. Материалы раздела распространяются
с учётом NDA. Публичное размещение недопустимо — репозиторий должен оставаться приватным.
