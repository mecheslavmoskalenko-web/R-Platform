# integration — Методики интеграции ИС с R-PLATFORMA

Отдельные выгрузки по драйверам интеграции. Полный свод методик находится
в руководстве администратора, раздел «Методики интеграции ИС с R-PLATFORMA».

### SNMP

Взаимодействие с сетевыми устройствами по стандартному протоколу SNMP.
Настройка драйвера сводится к одному свойству — `configFilePath`, пути к JSON-файлу
конфигурации. Конфигурация описывает множество обслуживаемых устройств: параметры
подключения (target, community, версия v1/v2c, транспорт udp4/udp6, порт, интервал
опроса, таймаут), массив опрашиваемых OID и массив триггеров с выражениями
и условиями генерации событий. Тип оборудования — только `SNMP_DEVICE`.
SNMP trap'ы в текущей версии не используются.

### Zabbix

Доступна начиная с версии R-PLATFORMA **3.6**. Драйвер получает список устройств
(hosts) и каналов (items, триггеры, интерфейсы) и генерирует события R-PLATFORMA
при достижении заданных значений. Настраивается через IP-адрес сервера, токен
доступа (создаётся в Zabbix в разделе Users → API tokens) и блок параметров MQTT.
Работа ведётся через панель «Конфигурация SCADA»: поиск оборудования → запрос
конфигурации → сохранение в БД → настройка оборудования и каналов → перезапуск
процесса драйвера.

## Полный перечень поддерживаемых интеграций

По оглавлению редакции руководства администратора от 19.12.2025 — 79 методик, включая:

**Протоколы и промышленные шины:** ModBus TCP, OPC, OPC DA, OPC UA, SNMP, ССТМК

**СКУД:** Sigur, Sigur Rest, PERCo, PERCo-Web, Bastion-3, Bolid, BolidOrionPro,
Global, Global PRO, КД PRO, Strazh, KeyGuard

**Видеонаблюдение:** Intellect, Trassir, Trassir-Client, SecurOS, RVI-VMS,
RVI-Оператор, VMS

**ОПС и периметр:** Satel Integra, ВОЛК, Firesec, FireSecNT, ECOS, Radescan,
ИСО Тополь, ПАК Stealth, ЭВС СУ24

**Инженерия и мониторинг:** BACnet, Zabbix, TFortis Teleport-1, TFortis Teleport-2

**Связь и оповещение:** Asterisk, GSM, Telegram (оповещение и запись), BAS-IP,
NEZABUDKA, ОК СС

**Прочее:** ARMAN, KRPRATEC, Strizh

## Соответствие проекту

Из перечня закрываются штатными драйверами: Intellect (ITV), Satel Integra, Sigur,
Bolid/ИСО «Орион», ВОЛК (через OPC), Zabbix, SNMP, BACnet, ModBus TCP, OPC UA.

Требуют разработки по этапам 2–3: Salto, НПЦ «Аспект» (АСКДРМ), Hikvision IP-домофония,
1С, ELMA, Hytera TETRA, ПАК АСДКУ, ПАК противопожарной защиты.
