## 2. Буква «ё» — непоследовательное написание, 14 записей

Один и тот же ангар записан тремя способами:

```
Ангар для вертолетов №1 (Основной)
Ангар для вертолета №2 с площадкой
Ангар для вертолёта №2
```

| Сейчас | Должно быть | `locid` |
|---|---|---|
| приема | приёма | 646, 2269, 2461, 2561, 3160, 3210 |
| Учет | Учёт | 1937, 1964 |
| приемки | приёмки | 2258, 3373 |
| вертолетов | вертолётов | 72 |
| вертолета | вертолёта | 9 |
| приемщиков | приёмщиков | 2971 |
| Тренажерный | Тренажёрный | 2585 |
| проем | проём | 314 |

Требуется решение: писать «ё» последовательно или последовательно не писать. Смешанное написание ломает поиск.

## Как проверялось

Наименования разобраны на словоформы и сверены со словарём русского языка. Профессиональная и техническая лексика, аббревиатуры и собственные имена из проверки исключены вручную. Перечень не претендует на полноту: слова, отсутствующие в словаре и не опознанные как опечатки, в список не попали.
